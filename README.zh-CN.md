# NMC5344 CS2 VRS 项目说明

本项目从 Valve 官方 GitHub 仓库保存可获取的 2024–2026 VRS，使用 R 清洗、构建月度面板和绘图。主要阅读入口是[中文探索解读](analysis/FINDINGS.zh-CN.md)和[英文发现](analysis/FINDINGS.md)。交付的是探索分析及建议，不是完整课程报告。

主分析使用 2024-08-06 至 2026-10-05 的 27 期月度 invitation 全球榜。最早恢复到的 2024 地区榜为 3 月 4 日，全球榜和详情从 4 月 22 日开始；其他 live 日期和历史修订也保存下来。没有为 1–2 月补造数据。

原始文件完整保存在本地 `data/raw/`，不上传到公开仓库。仓库提供处理后数据、来源清单、固定版本的下载与处理脚本、图表和解读。依照英文 README 的步骤，可以从相同官方提交重新生成数据。

几个必须注意的区别：

- 队名、公布名单、用于纵向分析的核心阵容延续线并不相同。
- Match ID 是单次模型计算的序号，不能跨快照当作永久比赛 ID。
- 官方分数受模型变化和当期归一化影响，不能将不同年份的同分视为同一能力。
- 2025 年 8 月后不足五人的 active roster 不能直接解释为换人数量。
- 未上榜不等于零分、最后一名或解散；首次观察到名单变化也不是真实转会日期。
- 分项本来就是评分公式的输入，分项与排名的相关性不能证明因果。

建议短报告围绕“Top 10 有多稳定”展开，用名次波动和一两个轨迹案例辅助。地区结构、阵容变化和分项分析可作为备选扩展。详细字段、方法、来源与测试结果见英文文档及 `output/validation/`。
