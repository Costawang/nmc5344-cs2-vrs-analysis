# Research questions

## Recommended core

1. How persistent was membership of the global VRS Top 10 across monthly invitation lists from August 2024 to the latest available 2026 snapshot?
2. Which eligible core lineages showed relatively stable or volatile official rankings, and how does observation coverage affect that comparison?
3. Which reproducibly selected rising, declining and stable trajectories help explain the aggregate pattern?

Use Top 10 continuity as the main question, mobility as supporting evidence, and one or two case trajectories as illustrations. A short course report should not try to answer every possible question.

## Optional extensions

4. How did regional representation within the global Top 20 change after the transition to a single region per roster?
5. Within a fixed model period, how do the published scoring components differ across rank groups?
6. Are first-observed lineup changes accompanied by different short-term rank trajectories?

The last question concerns association only. Changes to active-roster eligibility, irregular early publication, uncertain transfer timing and incomplete lineups limit its suitability as a primary question. No machine learning or causal identification is required for this release.
